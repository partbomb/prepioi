# 🔀 Урок 2: Условный оператор (if/else)

**🎯 Цель урока:** Научить компьютер принимать решения в зависимости от ситуации.

## 📖 Теория

Представь, что ты стоишь перед развилкой на дороге:
- **Если (if)** пойдешь направо — найдешь клад.
- **Иначе (else)** пойдешь налево — попадешь в болото.

Компьютер тоже умеет выбирать путь! Для этого мы используем конструкцию `if / else`.

### Базовый синтаксис
```cpp
if (условие) {
    // Этот код сработает, если условие ПРАВДА
} else {
    // Этот код сработает, если условие ЛОЖЬ
}
```

А что если дорог больше двух? Тогда используем `else if` (иначе если):
```cpp
if (условие1) {
    // ...
} else if (условие2) {
    // ...
} else {
    // ...
}
```

### Операторы сравнения (Как задавать вопросы?)
- `==` равно (Внимание! Одно `=` это положить в коробочку, а два `==` это вопрос "Они равны?")
- `!=` не равно
- `>` больше, `<` меньше
- `>=` больше или равно, `<=` меньше или равно

### Логические операторы (Сложные вопросы)
Иногда нужно задать сразу два вопроса:
- `&&` (И) — сработает, только если ОБА условия правда (Например: если ты сделал уроки `&&` помыл посуду -> можешь играть).
- `||` (ИЛИ) — сработает, если ХОТЯ БЫ ОДНО условие правда (Если идет дождь `||` идет снег -> возьми зонт).
- `!` (НЕ) — меняет правду на ложь и наоборот.

## 💻 Шаблон кода

Программа, которая определяет, какое из двух чисел больше:

```cpp
#include <iostream>

using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    
    if (a > b) {
        // Сработает, если a больше b
        cout << ">"; 
    } else if (a < b) {
        // Сработает, если a меньше b
        cout << "<";
    } else {
        // Если a не больше и не меньше, значит они равны!
        cout << "=";
    }
    
    return 0;
}
```

## 💡 Подсказки

<details>
<summary>Подсказка для задачи "Зарплата"</summary>
Чтобы найти максимальное из трех чисел `a, b, c`, можно написать так:
`int max_zp = a;`
`if (b > max_zp) max_zp = b;`
`if (c > max_zp) max_zp = c;`
То же самое для минимального. А потом просто вычесть!
</details>

<details>
<summary>Частая ошибка с if!</summary>
Никогда не ставь точку с запятой `;` сразу после `if (условие)`. Иначе компьютер подумает, что условие закончилось, и выполнит следующий код в любом случае!
</details>
