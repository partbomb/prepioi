# 🚀 Урок 1: Ввод и вывод данных (Input/Output)

**🎯 Цель урока:** Научиться "разговаривать" с компьютером — давать ему числа и получать ответы.

## 📖 Теория

Любая программа — это как умный помощник. Чтобы он что-то сделал, ему нужно дать исходные данные (**Ввод**), и после работы он должен показать результат (**Вывод**). 

В языке C++ мы используем специальные "уши" и "рот" компьютера:
- `cin` (читается как *си-ин*, от C-input) — это **"уши"** компьютера. Он слушает, что ты печатаешь на клавиатуре.
- `cout` (читается как *си-аут*, от C-output) — это **"рот"** компьютера. Он говорит тебе результат на экран.

### Структура программы
Каждая программа на C++ имеет свой "скелет", без которого она не сможет жить:

```cpp
#include <iostream> // Библиотека, чтобы компьютер умел говорить и слушать

using namespace std; // Используем стандартные слова, чтобы не писать длинно

int main() {         // Это самая главная функция (сердце программы)
    // Твой код будет здесь!
    return 0;        // Сообщаем компьютеру, что всё прошло отлично
}
```

### Переменные (Коробочки для данных)
Прежде чем прочитать данные, их нужно куда-то положить. Представь, что переменная — это пустая коробочка с именем.
- `int` — коробочка для целых чисел (например: 5, -10, 100).
- `double` — коробочка для чисел с точкой (например: 3.14, -0.5).

### Как работают cin и cout
Стрелочки показывают, куда идут данные!
- `cin >> a;` (Данные с клавиатуры идут **в** коробочку `a`)
- `cout << a;` (Данные из коробочки `a` вылетают **на** экран)

## 💻 Шаблон кода

Вот готовая программа, которая читает два числа и выводит их сумму:

```cpp
#include <iostream> // Подключаем библиотеку ввода-вывода

using namespace std;

int main() {
    int a, b; // Создаем две пустые коробочки для целых чисел
    
    // Слушаем с клавиатуры два числа и кладем их в a и b
    cin >> a >> b; 
    
    // Считаем сумму и сразу выводим её на экран
    cout << a + b; 
    
    return 0; // Завершаем программу
}
```
