# 🛠️ Урок 7: Функции (Functions)

**🎯 Цель урока:** Понять, зачем нужны функции, как их создавать, передавать в них параметры и получать результат (возврат значения).

**📖 Теория:**

Представь, что **функция — это кулинарный рецепт**.
Один раз кто-то написал рецепт (создал функцию) выпечки пирога. Теперь, каждый раз, когда ты хочешь пирог, тебе не нужно заново придумывать, как его готовить. Ты просто берешь рецепт, даешь ему ингредиенты (параметры), и на выходе получаешь готовый пирог (результат).

**Зачем нужны функции?**
1. **Чтобы не повторять код (DRY - Don't Repeat Yourself).** Если кусок кода используется несколько раз, лучше вынести его в функцию.
2. **Чтобы код было легче читать.** Согласись, `cookPizza(ingredients)` звучит понятнее, чем 50 строк сложного кода.

**Как устроена функция?**
У функции есть:
*   **Тип возвращаемого значения:** Что она нам отдаст? Число (`int`), строку (`string`)? Если функция ничего не отдает, а просто что-то делает (например, печатает в консоль), то тип будет `void` (пустота).
*   **Имя:** Как мы будем ее вызывать (например, `sum`, `printHello`).
*   **Параметры:** Ингредиенты, которые мы ей даем в скобках.

**Где писать функции?**
Функции нужно писать **ДО** главной функции `main()`. Программа всегда начинает работу с `main()`, и если она там встретит вызов функции, она должна уже знать о ее существовании.

**💻 Шаблон кода:**

```cpp
#include <iostream>
#include <string>
using namespace std;

// Функция 1: Тип void. Ничего не возвращает, просто здоровается.
// Параметр: строка name.
void sayHello(string name) {
    cout << "Привет, " << name << "!" << endl;
}

// Функция 2: Возвращает int. Находит сумму двух чисел.
// Параметры: два числа a и b.
int getSum(int a, int b) {
    int result = a + b;
    return result; // Команда return отдает результат обратно!
}

// Функция 3: Возвращает максимум из двух чисел.
int getMax(int x, int y) {
    if (x > y) {
        return x;
    } else {
        return y;
    }
}

int main() {
    // 1. Вызываем функцию sayHello
    sayHello("Иван");
    sayHello("Анна");

    // 2. Вызываем функцию getSum и сохраняем результат
    int x = 5;
    int y = 7;
    int sum = getSum(x, y);
    cout << "Сумма " << x << " и " << y << " равна " << sum << endl;

    // 3. Вызываем функцию прямо внутри cout
    cout << "Максимум из 10 и 25: " << getMax(10, 25) << endl;

    return 0;
}
```

**💡 Подсказки:**

<details>
<summary>Как найти минимум из 4 чисел?</summary>
Сначала напиши функцию `min2(a, b)`, которая находит минимум из двух чисел. 
Потом внутри `main` или внутри новой функции `min4(a, b, c, d)` используй ее так: `min2(min2(a, b), min2(c, d))`.
</details>

<details>
<summary>Как решить задачу про арбуз?</summary>
Арбуз весит `w` килограмм. Его нужно разделить на две части, вес каждой должен быть четным. Подумай, какими могут быть эти части. Не забудь про случай, когда `w == 2` (его нельзя разделить на две четные части).
</details>
