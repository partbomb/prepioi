# 🔄 Урок 4: Цикл `while`

**🎯 Цель урока:** Понять, как работает цикл `while` (пока), чем он отличается от `for`, и научиться управлять им с помощью `break` и `continue`.

**📖 Теория:**

Цикл `while` переводится как "пока". Он работает так: **ПОКА** условие верно (истинно), делай что-то.

Представь, что ты ждешь автобус на остановке.
*   **Твое условие:** Автобус еще не приехал.
*   **Твое действие:** Ты стоишь и ждешь.
Как только автобус приедет (условие станет ложным), ты перестанешь ждать и сядешь в него (цикл закончится).

**Чем `while` отличается от `for`?**
*   `for` мы используем, когда **точно знаем**, сколько раз нужно повторить действие (например, "сделай 5 раз").
*   `while` мы используем, когда **не знаем** заранее количество повторений, но знаем, **при каком условии** нужно остановиться (например, "делай, пока не найдешь нужную цифру").

**Бесконечный цикл и как из него выйти (`break`)**
Если условие всегда истинно, цикл никогда не закончится. Это называется бесконечным циклом. Чтобы выйти из него досрочно, используется команда `break` (переводится как "сломать", "прервать").

**Команда `continue` (пропустить)**
Иногда нужно не прерывать весь цикл, а просто пропустить текущий шаг и перейти к следующему. Для этого используют `continue`.

**Цикл `do-while`**
Обычный `while` сначала проверяет условие, а потом делает. А `do-while` сначала делает действие хотя бы один раз, а потом проверяет условие (например, как лотерея: сначала купил билет, потом узнал, выиграл или нет).

**💻 Шаблон кода:**

```cpp
#include <iostream>
using namespace std;

int main() {
    // Пример 1: Обычный while. Выводим числа от 1 до 5
    int i = 1;
    cout << "Считаем до 5:" << endl;
    while (i <= 5) { // Пока i меньше или равно 5
        cout << i << " ";
        i = i + 1; // Не забываем увеличивать i, иначе будет бесконечный цикл!
    }
    cout << endl << "----------------" << endl;

    // Пример 2: Обработка цифр числа
    // Задача: найти сумму цифр числа
    int n = 12345;
    int sum = 0;
    cout << "Сумма цифр числа " << n << ":" << endl;
    while (n > 0) { // Пока от числа хоть что-то осталось
        int last_digit = n % 10; // Берем последнюю цифру (остаток от деления на 10)
        sum = sum + last_digit; // Прибавляем ее к сумме
        n = n / 10; // Отрезаем последнюю цифру (целочисленное деление на 10)
    }
    cout << sum << endl;
    cout << "----------------" << endl;

    // Пример 3: Использование break
    int password = 0;
    while (true) { // Бесконечный цикл
        // cout << "Введите пароль (1234): ";
        // cin >> password; // Раскомментируй, чтобы проверить ввод
        password = 1234; // Имитация ввода
        
        if (password == 1234) {
            cout << "Пароль верный! Добро пожаловать." << endl;
            break; // Выходим из цикла
        } else {
            cout << "Неверный пароль. Попробуйте еще раз." << endl;
        }
    }

    return 0;
}
```

**💡 Подсказки:**

<details>
<summary>Как отрезать последнюю цифру у числа?</summary>
Чтобы получить последнюю цифру числа, используй остаток от деления на 10: `n % 10`. 
Чтобы отрезать эту цифру и оставить остальное число, используй целочисленное деление на 10: `n = n / 10;`.
</details>

<details>
<summary>Как проверить, является ли число степенью двойки?</summary>
Пока число делится на 2 без остатка (`n % 2 == 0`), дели его на 2 (`n = n / 2`). Если в конце осталась 1, значит это была степень двойки.
</details>
