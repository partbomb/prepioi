## 📖 О проекте

**CP-Roadmap** — это не очередная тестирующая система, а **маршрутный лист (roadmap) для самообучения** спортивному программированию.

Проект создан учеником 11 класса, который прошёл весь этот путь сам и знает главные боли новичков. Здесь ученик получает:

- 🧠 **Понятную теорию** — простым, человеческим языком, без академической сухости
- ✅ **Готовый чеклист задач** — с ссылками на лучшие задачи из уже существующих платформ
- 💡 **Подсказки без спойлеров** — скрытые блоки помощи для тех, кто застрял

## 🗺️ Методология обучения — «Воронка платформ»

Обучение построено на **плавной смене платформ**, чтобы сложность росла постепенно и не отпугивала:

### 🟢 Уровень 1 — «Песочница» → [ACMP.ru](https://acmp.ru)

> **Цель:** Привыкнуть к тестирующим системам, научиться считывать и выводить данные, освоить базовые типы.

- Задачи в **3–5 строк** с простым русскоязычным описанием
- Раздел «Начинающим» — идеальный старт для полного новичка
- Мгновенная обратная связь: сдал → увидел результат

### 🟡 Уровень 2 — «Тренажёрный зал» → [Informatics.msk.ru](https://informatics.msk.ru)

> **Цель:** Набить руку на классических алгоритмах и конструкциях языка.

- Тематические курсы: отдельные наборы на **циклы while**, **массивы**, **строки**
- Структурированная прокачка навыков
- Каждая тема — отдельный «тренажёр»

### 🔴 Уровень 3 — «Большой спорт» → [Codeforces.com](https://codeforces.com)

> **Цель:** Научиться придумывать идеи, оптимизировать код, работать с Time Limit и Memory Limit.

- Задачи из архива с рейтингом **800–1000**
- Изучение структур данных (`vector`, `set`, `map`)
- Подготовка к настоящим соревнованиям

```
📈 Прогресс ученика:

  ACMP (Песочница)     Informatics (Тренажёр)     Codeforces (Спорт)
  ┌─────────────┐      ┌──────────────────┐       ┌────────────────┐
  │ Ввод/Вывод  │──►   │ Циклы            │──►    │ Задачи 800+    │
  │ Условия     │      │ Массивы          │       │ STL контейнеры │
  │ Простые     │      │ Строки           │       │ Оптимизация    │
  │ вычисления  │      │ Функции          │       │ Контесты       │
  └─────────────┘      └──────────────────┘       └────────────────┘
```
