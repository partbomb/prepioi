# CP-Roadmap — Навигатор по олимпиадному программированию

Это **НЕ базовый курс программирования**. Это дорожная карта по алгоритмам и структурам данных, необходимым для успешного участия в олимпиадах по программированию.

## 🎓 Не знаешь основ C++?
Если ты только начинаешь свой путь и еще не уверен в базовом синтаксисе языка, сначала пройди [бесплатный курс на Stepik](https://stepik.org/course/363/promo), а потом возвращайся сюда за алгоритмами!

## 🗺️ О проекте
Здесь собраны ключевые алгоритмические темы, разбитые на уровни сложности. Темы распределены так, чтобы ты мог изучать их постепенно:
1. **Tier 1**: Основы (сортировка, бинарный поиск, префиксные суммы)
2. **Tier 2**: Продвинутые техники (жадные алгоритмы, два указателя, рекурсия, базовое ДП)
3. **Tier 3**: Сложные структуры и алгоритмы (графы, теория чисел, деревья, продвинутое ДП, строковые алгоритмы)

## 🚀 Как пользоваться
1. Выбери доступную тему в дереве навыков
2. Изучи краткую теорию и шаблон кода
3. Реши задачи на Codeforces по ссылкам
4. Отметь выполненные задачи и переходи к следующей теме
