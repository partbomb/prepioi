## 📌 О проекте

Это дорожная карта (roadmap) для самостоятельного изучения основ спортивного программирования на C++. Проект ориентирован на школьников 5–9 классов, которые только начинают свой путь в олимпиадах. 

Курс создан учеником 11 класса, который сам прошел этот путь и собрал все необходимые материалы, задачи и теорию в одном месте — прямо здесь, на GitHub. Никаких сложных сайтов, только удобные Markdown-файлы.

## 🛠 Как пользоваться

1. **Выберите тему** — перейдите в нужную папку из списка ниже.
2. **Изучите материал** — прочитайте теорию и разберите шаблоны кода.
3. **Решайте задачи** — переходите по ссылкам на задачи, а затем возвращайтесь сюда и отмечайте свой прогресс в чек-листе.

## 💻 Платформы для решения задач

В рамках этого курса мы используем несколько проверенных платформ:
* **[ACMP (Школа программиста)](https://acmp.ru)** — отлично подходит для самых азов. Простые формулировки задач и понятный интерфейс.
* **[Informatics](https://informatics.msk.ru/)** — огромная база задач по всем темам школьного курса информатики и алгоритмам.
* **[Codeforces](https://codeforces.com/)** — главная мировая платформа для спортивного программирования. Мы перейдем к ней на более продвинутых этапах.
