# 📝 Урок 6: Строки (Strings)

**🎯 Цель урока:** Научиться работать с текстом, сохранять слова и предложения в переменные типа `string` и управлять отдельными буквами.

**📖 Теория:**

До этого мы работали в основном с числами (`int`, `double`). А что если нам нужно сохранить имя пользователя или какое-то сообщение? Для этого существует тип данных `string` (строка).

Представь, что **строка — это поезд**, а **каждый вагон — это одна буква** (или пробел, или знак препинания). 
Как и в массивах (из прошлого урока), вагоны нумеруются с **НУЛЯ**.

Например, строка `s = "Hello"`:
*   `s[0]` — это буква 'H'
*   `s[1]` — это буква 'e'
*   `s[4]` — это буква 'o'

**Что можно делать со строками?**
*   **Склеивать (конкатенация):** Можно сложить две строки с помощью плюса `+`. `"Привет, " + "мир!"` получится `"Привет, мир!"`.
*   **Узнать длину:** Узнать, сколько всего вагонов (символов) в поезде, можно с помощью команды `s.length()`.
*   **Перебирать буквы:** С помощью цикла `for` можно пройтись по всем буквам от 0 до `s.length() - 1` и что-то с ними сделать (например, заменить маленькие на большие).

**💻 Шаблон кода:**

```cpp
#include <iostream>
#include <string> // Обязательно подключаем библиотеку для работы со строками!
using namespace std;

int main() {
    // 1. Создание строки
    string name = "Alice";
    string greeting = "Hello, ";

    // 2. Склеивание строк (конкатенация)
    string message = greeting + name + "!";
    cout << message << endl; // Выведет: Hello, Alice!

    // 3. Узнаем длину строки
    cout << "Длина имени " << name << " равна " << name.length() << " букв." << endl;

    // 4. Обращаемся к конкретным буквам (индексы с 0!)
    cout << "Первая буква: " << name[0] << endl;
    cout << "Последняя буква: " << name[name.length() - 1] << endl;

    // 5. Перебор всех букв в строке с помощью цикла
    cout << "Буквы через пробел: ";
    for (int i = 0; i < name.length(); i++) {
        cout << name[i] << " ";
    }
    cout << endl;

    // Пример: Чтение строки с пробелами (закомментировано)
    /*

    // cin >> s; // Читает только одно слово до первого пробела

    cout << "Вы ввели: " << s << endl;
    */

    return 0;
}
```

**💡 Подсказки:**

<details>
<summary>Как проверить, является ли буква цифрой?</summary>
В C++ символы имеют коды. Символы цифр идут по порядку: '0', '1', '2' ... '9'. 
Можно просто написать условие: `if (c >= '0' && c <= '9')`.
</details>

<details>
<summary>Как сделать строку палиндромом наоборот?</summary>
Можно создать новую пустую строку `string rev = "";`, пройтись по исходной строке циклом с конца до начала (от `s.length()-1` до `0`) и добавлять каждую букву к `rev`. Затем сравнить `s == rev`.
</details>
