# 📦 Урок 5: Массивы (Arrays)

**🎯 Цель урока:** Узнать, что такое массивы, как в них хранить много данных одного типа, и научиться находить в них минимум, максимум и сумму элементов.

**📖 Теория:**

Представь школьную раздевалку. В ней стоит длинный ряд шкафчиков. Каждый шкафчик имеет свой порядковый номер, и в каждый шкафчик можно положить одну куртку.

**Массив в программировании — это и есть такой ряд шкафчиков!**
Только вместо курток там лежат данные (например, числа), а номера шкафчиков называются **индексами**.

**Самое главное правило массивов:**
В C++ нумерация шкафчиков (индексов) всегда начинается с **НУЛЯ (0)**!
Если в массиве 5 элементов, то их индексы будут: 0, 1, 2, 3, 4.

**Зачем нужны массивы?**
Если тебе нужно сохранить оценки 3 учеников, ты можешь создать 3 переменные: `a`, `b`, `c`. 
Но если учеников 1000? Создавать 1000 переменных — это безумие! Проще создать один массив размером 1000.

**Основные операции с массивом:**
1. **Создание (объявление):** Мы говорим, какой тип данных там будет лежать, имя массива и его размер.
2. **Заполнение:** Обычно используют цикл `for`, чтобы пройтись от 0 до конца массива и положить значения.
3. **Чтение:** Снова используем цикл `for`, чтобы посмотреть, что лежит в каждом шкафчике.
4. **Линейный поиск:** Проверяем каждый элемент по очереди, пока не найдем то, что нужно.

**💻 Шаблон кода:**

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. Создаем массив на 5 целых чисел
    // int arr[5]; 
    
    // Сразу создадим массив и заполним его числами
    int marks[5] = {4, 5, 3, 5, 4}; 

    // Выведем первую оценку (индекс 0)
    cout << "Первая оценка: " << marks[0] << endl;

    // 2. Вывод всех элементов массива с помощью цикла for
    cout << "Все оценки: ";
    for (int i = 0; i < 5; i++) {
        cout << marks[i] << " ";
    }
    cout << endl;

    // 3. Найдем сумму всех элементов
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum = sum + marks[i];
    }
    cout << "Сумма всех оценок: " << sum << endl;

    // 4. Поиск максимального элемента (самой высокой оценки)
    int max_mark = marks[0]; // Пусть первый элемент будет максимумом
    for (int i = 1; i < 5; i++) { // Начинаем с 1, так как 0-й уже взяли
        if (marks[i] > max_mark) {
            max_mark = marks[i]; // Нашли кого-то больше, обновляем максимум!
        }
    }
    cout << "Самая высокая оценка: " << max_mark << endl;

    // Пример: Чтение массива с клавиатуры (закомментировано)
    /*
    int n;
    cin >> n; // размер массива
    int a[100]; // создаем массив с запасом
    for(int i = 0; i < n; i++) {
        cin >> a[i]; // считываем каждый элемент
    }
    */

    return 0;
}
```

**💡 Подсказки:**

<details>
<summary>Как проверить, что элемент четный?</summary>
Используй остаток от деления на 2. Если `arr[i] % 2 == 0`, то элемент четный.
</details>

<details>
<summary>Как сравнить с предыдущим элементом?</summary>
В цикле `for` начинай с `i = 1`. Текущий элемент это `arr[i]`, а предыдущий — это `arr[i - 1]`.
</details>
