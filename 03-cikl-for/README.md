# 🔄 Урок 3: Цикл for

**🎯 Цель урока:** Научиться заставлять компьютер повторять действия много раз, чтобы не писать один и тот же код снова и снова.

## 📖 Теория

Представь, что тебе нужно пробежать 10 кругов на стадионе. Ты же не говоришь себе: "Я бегу круг. Я бегу круг. Я бегу круг..." (и так 10 раз). Ты говоришь: "Я буду бежать, пока счетчик кругов не достигнет 10".

В программировании для этого нужен **цикл `for`**. Он идеален, когда ты заранее знаешь, сколько раз нужно повторить действие.

### Анатомия цикла for
У цикла `for` есть три важные части внутри круглых скобок:
```cpp
for (старт; условие_работы; шаг) {
    // Тело цикла (то, что повторяется)
}
```
1. **Старт:** Откуда начинаем считать? (например, `int i = 1`). Выполняется один раз в самом начале.
2. **Условие:** До каких пор бежим? (например, `i <= 10`). Цикл работает, пока это ПРАВДА.
3. **Шаг:** Как меняется счетчик после каждого круга? (например, `i++`, что значит увеличить `i` на 1).

В 99% случаев цикл выглядит так:
```cpp
for (int i = 0; i < n; i++) {
    // Повторится ровно n раз
}
```

## 💻 Шаблон кода

Давай напишем программу, которая выводит квадраты чисел от 1 до N, и заодно считает их сумму:

```cpp
#include <iostream>

using namespace std;

int main() {
    int n;
    cin >> n; // Допустим, мы ввели 5
    
    int sum = 0; // Сюда будем копить сумму. Изначально там ноль!
    
    // Цикл побежит от 1 до n включительно
    for (int i = 1; i <= n; i++) {
        cout << i << " в квадрате = " << i * i << endl; // Выводим квадрат
        
        sum = sum + i; // Добавляем текущее число в копилку
    }
    
    cout << "Сумма чисел от 1 до " << n << " равна: " << sum;
    
    return 0;
}
```

## 💡 Подсказки

<details>
<summary>Как считывать много чисел?</summary>
Если в задаче сказано, что дано число N, а потом N чисел, это делается так:
```cpp
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    // Что-то делаем с x
}
```
</details>

<details>
<summary>Секреты `i++` и `i--`</summary>
`i++` — это сокращение от `i = i + 1`.
`i--` — это сокращение от `i = i - 1`.
Если нужно идти в обратную сторону, цикл будет таким: `for(int i = 10; i > 0; i--)`.
</details>
